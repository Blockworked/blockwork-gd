# Blockwork

Runs [Blockwork](https://blockworked.com) macros inside Geometry Dash, synced to level attempts.

Blockwork's recording and playback engine is built into the mod, so nothing else needs to be running. On every attempt start (entering a level, or retrying after a death) it either runs the chosen macro or starts recording. On every attempt end it can stop, so input never bleeds into the next attempt.

Turn the mod on and choose what happens on level start in its settings. Under Proton, point "Blockwork Config Dir Override" at the Linux Blockwork config folder so the mod sees the desktop app's macros.
